# 🌙 LunaMuse

LunaMuse is an aesthetic frontend music player designed around a soft, dreamy night-inspired theme. The project focuses on creating an immersive visual experience using HTML, CSS, and JavaScript, with designed SVG as the main visual highlight.

---

## ✨ Features

* 🎵 **Music Player:** Smooth audio playback with play/pause functionality
* ⏱️ **Progress Controls:** Interactive music progress bar and seek controls
* 🎶 **Song Playlist:** Dynamic track selection and playlist management
* 🌙 **Custom Crescent Moon:** Glowing moon design crafted directly into the UI
* 🌷 **Custom Tulip Illustrations:** artwork using SVG and CSS
* ⌨️ **Shortcut Controls:** Full hotkey support for seamless music control
* 🎨 **Aesthetic Night UI:** Soft, minimal, dreamy visual environment
* 📱 **Responsive Design:** Mobile-optimized layout with fluid SVG scaling

---

## 🎨 Design Highlights

The main focus of LunaMuse is its visual design, CSS craftsmanship, and scalable graphics.

### 🌙 Crescent Moon
A custom crescent moon element was created using glowing filter effects and pure CSS gradients as part of the interface to build the project's dreamy nighttime atmosphere.

### 🌷 SVG Tulips
The tulip illustrations were designed using **SVG and CSS**, adding a visual element to the music player rather than relying on external images. The graphics feature:
* **Custom SVG Paths & Gradients:** Dynamic vector rendering that scales sharply across all screen resolutions.
* **Responsive Scaling:** Responsive `viewBox` settings and CSS scaling properties so elements look great on both desktop and mobile.

---

## ⌨️ Shortcut Controls

The player includes convenient keyboard shortcuts to easily control playback without using the mouse:

~ `Space` - Play / Pause 
~ `←` - (Left Arrow) | Previous song
~ `→` - (Right Arrow) | Next song 
~ `↑` - (Up Arrow) | Volume up 
~ `↓` - (Down Arrow) | Volume down

## 🌌 Project Concept
LunaMuse combines music with a calm, moonlit aesthetic. The interface was designed to feel soft and atmospheric while keeping the controls simple and accessible.
The project mainly explores frontend design, CSS styling, SVG creation, JavaScript interactions, and keyboard accessibility.
